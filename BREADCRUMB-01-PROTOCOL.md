# BREADCRUMB-01 PROTOCOL

**Classification:** Loop-breaker  
**Target constraint:** Visibility-time-validation trap  
**Time to deploy:** 14 days  
**Resource cost:** 4-6 hours total  
**Status:** ACTIVATED

---

## MISSION OBJECTIVE

Publish ONE methodology artifact in findable location. Not complete. Not polished. Sufficient to be discovered by adjacent travelers and self-selecting testers.

---

## ARTIFACT SELECTED

**Edge-finding protocols**

**Rationale:** 
- Highest novelty = highest signal in noise
- Most likely to attract the right adjacent travelers (people already exploring AI collaboration depth)
- Doesn't require tooling to test (unlike Facets)
- The trigger phrases ("edge bird," "scatter probability") are memorable anchors
- Live example exists: the conversation that generated this protocol

---

## MINIMUM VIABLE FORM

**Title:** "Edge-Finding: A Human-AI Collaborative Discovery Practice"

**Structure:**
1. The problem it solves (2-3 sentences)
2. The core metaphor (elastic tether, not chain)

**Visuals:** Optional. Don't let them block shipping.

## PUBLICATION VECTOR

**Primary:** GitHub repo + LinkedIn article pointing to it

**Repo name:** `edge-finding`

**Rationale:**
- GitHub = permanence, forkability, technical credibility
- LinkedIn = existing network, immediate distribution
- Combo creates two findability vectors
- GitHub lets people *use* it, not just read it

## EXECUTION SEQUENCE

```
DAY 1-2:   Draft core document (60-90 min)
DAY 3:     Let it sit. Don't touch.
DAY 4:     Edit once. Cut 20%. (30 min)
DAY 5-7:   Create GitHub repo. Add README. (30 min)
DAY 8-10:  Write LinkedIn post pointing to repo. (30 min)

```

**CRITICAL RULE:** Ship on day 14 even if it feels incomplete. Incomplete-and-visible beats complete-and-invisible.

---

## SUCCESS METRICS

**Not measuring:**
- Views, likes, follower count

**Measuring:**
- Did anyone fork/star the repo? (signal: practitioners found it)
- Did anyone comment with their own experience? (signal: resonance)
- Did anyone reach out directly? (signal: adjacent traveler detected)
- Did you learn something about transferability from responses? (signal: validation data)

**Success threshold:** 1 meaningful response from someone you don't already know.
